# lun-prop-firm-playbook：Prop firm／資金放大路線（交易倫版）

> 本 skill 係交易倫 11-skill 體系嘅**應用場景層**——解決**識交易但本金太細**嘅問題：先有數據（→ `lun-backtesting-method`），再揀路線（線上機構考試 vs 資金扶持計劃），用倒推計劃通過考試，最後管好放大咗嘅資金同心態。主教材係 xmHaONnNrCw（FTMO 40 萬一次通過，**親歷**）；規則講解係 rE21_onS0uo；Axi Select 兩片（91Hpt_LyJSE, nzZ5oqmLjhM）係**導流合作（sponsored）內容**，所有計劃數字引用必須帶推廣性質標註。核心思維：「就是資金大小,跟你的教育態度是綁定的」（48pCaOfGGmA；教育＝交易）。所有引文照錄筆記/逐字稿原文（含 ASR 誤字；**交易保釋機構＝prop firm／撥資機構**、AXE/AXIS/AXIE/C Select＝Axi Select，正字對照見 `analysis/lun_trading_profile.md` §5）。完整原話證據全錄喺 [references/evidence.md](references/evidence.md)。

## When to Use（何時使用）

用呢個 skill 當你需要：

- 判斷應唔應該行 prop firm 路：本金夠唔夠、數據夠唔夠、時機啱唔啱
- 理解 prop firm 商業模式與風險（「線上機構的資金都不是真的資金」、考試費生意、拒絕出金風險）
- 規劃由零開始嘅職業路徑：敢敢開始（200 美金試三個月）→ 打磨 → 做大（prop firm 補本金缺口）
- 為機構考試（FTMO 類：10%/5% 兩階段、每日 5%/最大 10% 虧損、80% 分潤）做倒推計劃：風險 %、連虧遞減、盈虧比門檻、需要幾多筆咩級數嘅交易先達標
- 理解 Axi Select 跟單晉級計劃嘅規則結構（**推廣合作內容**，引用必註明）
- 設定合理回報期望：月均 2%、由每月開銷反推所需本金、500→100 萬嘅帳戶增長藍圖（講者藍圖非驗證統計）
- 處理通過考試/大額出金之後嘅帳戶管理態度（戒飄、用大資金態度管理）

**唔應該用嘅情況**：

- 一般倉位計算、1%–2% 風險、等額風險、連虧降倉嘅通用規則 → 用 `lun-risk-management`（本 skill 只持有 prop firm 場景嘅特定上限，如「參加撥資機構單筆風險不可超過 1%」）
- 考試用系統嘅策略規則本身（Pivot Point 設定、假突破/吞噬觸發）→ 用 `lun-price-action-toolkit`；時段選擇（倫敦/紐約、時間出場）→ `lun-kill-zones-timing`
- 考試前嘅 50–100 筆數據點樣回測/記錄得嚟 → 用 `lun-backtesting-method`（本 skill 只管**有咗數據先好考**呢個門檻）
- 飄/報復交易/得失心嘅心理機制本身 → 用 `lun-trading-psychology`
- 多時框共識流程（考試打法要求嘅日線/4小時/1小時同向共識）→ `lun-multi-timeframe-analysis`

## Workflow（分析流程）

按佢嘅路線圖行：點解要行 → 前提檢查 → 揀路線 → 考試計劃 → 考試打法 → 晉級計劃 → 增長藍圖 → 通過之後。

**Step 1 — 定位：問題係資金，唔係技術**

- 核心診斷：「大家遇到最大的問題是什麼呢?就是資金不夠大」「你要把小資金滾到很大,太久,太難,太痛苦了,幾乎不可能」（nzZ5oqmLjhM【推廣合作】語境，但同無贊助片口徑一致）；「其實問題不是我本金小罷了,是我的思維一開始就錯了」（48pCaOfGGmA）。
- 算術論證：「1,000塊的資金,5%的回報也就是50美金罷了」「就連要付電費其實也是不夠的」（91Hpt_LyJSE【推廣合作】）；「500美金,1%的回報就只有5塊美金。但是呢,40萬美金,1%的回報就4000美金了」（48pCaOfGGmA）。
- 心理機制：資金太小→得失心重→急→激進（91Hpt_LyJSE, OnjOO0QyVUU）；「大資金會逼你成熟,認真,而小資金會逼你衝動,讓你的賭信給拉滿」（48pCaOfGGmA；賭信＝賭性）。反面鐵律：唔好以小博大靠賭翻身（48pCaOfGGmA）。
- 時間觀：「所以在交易裡面的時間不等於金錢」——一天不到一小時＋大資金小回報，先係佢嘅五位數收入公式（rE21_onS0uo）。

**Step 2 — 前提檢查：數據先於考試**

- 硬門檻：「你最少最少需要50到100筆交易」數據（連虧/盈虧比/勝率/持倉時間）先可評估系統；未有就「你千萬不要去參加交易機構考試」「你一定會失敗的」（rE21_onS0uo）。數據點樣得嚟 → `lun-backtesting-method`。
- 由零開始三步框架（mDpbsw81ftI）：①敢敢開始——200 美金／三個月試水，「這三個月的重點不是要賺錢」「而是要看交易到底適不適合你」；②打磨——三檢查點（睇圖有清晰步驟／執行一致／識自我修正）＋交易日記；③做大——用 prop firm 解決本金問題，「前提是你要有一個穩定的交易表現」。
- 一致性挑戰：「有沒有辦法在連續50筆交易可以做到一致性,持續執行一個交易策略,一個規則」（48pCaOfGGmA）。

**Step 3 — 揀路線：機構考試 vs 資金扶持（雙選項平行呈現）**

- 兩條路（48pCaOfGGmA）：機構考試（「比如說FTMO,Top Step這一些,就是付費去參加機構考試」）vs 資金扶持計劃（Axi Select 類，500 美金起步）。佢嘅次序**偏好**：先喺扶持計劃磨練，穩定咗先考試——「因為考試費很貴,重考不划算」。
- 風險認知（91Hpt_LyJSE【推廣合作】語境下對 prop firm 嘅批評，引用時註明利益關係）：「大家都知道,線上機構的資金都不是真的資金,都是模擬舱來的」「這些線上機構賺錢的方式就是考試費」「他們隨時都可以拒絕你的出金」。
- 但佢冇否定考試路：「你機構考試是可以拿那種出名大的可以去考,同時AXIS Select也不要放過,我們都錯」（91Hpt_LyJSE【推廣合作】；ASR 疑＝兩個都做）——**（推測）**如果 ASR 原意係『兩個都做』，即佢喺贊助語境下主張雙軌並行；原句 ASR 損壞，唔可以當確定口徑。旁證（非同句）：佢本人 FTMO 滿級＋自述有參加 Axi Select。

**Step 4 — 考試倒推計劃（FTMO 親歷主教材 xmHaONnNrCw）**

- 規則（as-stated 2025-12-17）：(transcript)「第一階段�是你要做到10%的回報�第二階段�你要做到5%的回報�然後�最大虧損都是10%」；rE21_onS0uo 版（as-stated 2025-08-06，以示範網站為例）：1 萬美金考試費「大約是89」（另有 155 歐元檔）、無時間限制、(transcript)「每一天不可以虧超過5%,」最大虧損 10%、通過後 (transcript)「80%的回報會分給你。」爆倉唔使賠錢（虛擬帳戶）。
- 倒推法（佢嘅招牌思維）：(transcript)「推倒�如果我的單比風險是1%的話�那我可以連虧10次」——由可連虧次數同達標組合（一筆 1比10，或兩筆 1比3 加一筆 1比4）反推規則，計掂先開始：「我一參加的時候Ｖ我就已經很清楚知道�我自己一定會通過這個考試了」。
- 考試風控三規則：①單筆風險 1%；②連虧遞減——(transcript)「連虧5單之後�我一定把風險砍一半」由 1% 降到 0.5%，令自己「我可以連虧15次」；③盈虧比門檻——(transcript)「1比3的交易機會�對不起�我不做」，實際搵嘅機會「盈亏比都是1比5起跳的」。（通用風控規則 → `lun-risk-management`；1:3 係考試場景口徑，同其他情境嘅 1:1/1:2 門檻分層見 profile §7.3.2。）
- 打法：挑剔（「答案是�你要非常非常的挑剔」）＋多時框共識（「就是在日線圖4小時�1小時都是指著同一個方向的」，流程 → `lun-multi-timeframe-analysis`）＋固定看盤時間、唔用手機、每筆截圖記錄（記錄法 → `lun-backtesting-method`）。考試期間自述數據：「盈亏比�基本上都維持1比5�然後勝率是50%」（自述，未對帳）。

**Step 5 — 考試用短線系統（親歷，7j7_mhfda38）與 prop firm 特定限制**

- 佢考機構時用嘅黃金短線系統概要：5/15 分鐘圖＋日線 Pivot、只做倫敦/紐約時段、Pivot 位有 rejection/假突破先順大趨勢入場、「我們不要hold overnight」——「這一套系統是我剛開始參加機構考試時用的系統,那時候幾乎每兩個星期我都可以出境五位數美金。」（出境＝出金；自述，未對帳。）具體規則 → `lun-price-action-toolkit`；時段細節 → `lun-kill-zones-timing`。唔過夜片中講嘅理由係情緒壓力——隔天見大反轉會「然後覺得很壓力。然後沮喪。開始情緒化交易。」（7j7_mhfda38）；（推測）呢個習慣喺考試帳戶場景下同時起到保護作用，本 skill 持有嘅係考試場景呢層應用。
- Prop firm 特定風險上限：「如果你是參加交易保釋機構的話,你想要成為5位數、6位數美金交易員的話,那你的單比風險不可以超過1%。」（fLN20X1dP48；交易保釋機構＝撥資機構）；新系統/新機構起步「如果你的單比風險是0.25%的話」10% 上限下「你最少可以收集40比的交易數據」（rE21_onS0uo；比＝筆）。

**Step 6 —【推廣合作】Axi Select 晉級規則（91Hpt_LyJSE, nzZ5oqmLjhM）**

> 本 Step 全部內容出自兩片導流合作影片，數字係贊助語境下嘅陳述，as-stated 2025-08/10月，隨時可改，只可以連同呢兩重標註一齊引用。兩片口徑有出入處平行照錄，唔好合併。

- 計劃本質：「基本上就是會有資金去跟你的單」「最高可以高達100萬美金的資金」「中間產生的利潤,就會有最高80%的分層會分給你的」（nzZ5oqmLjhM；分層＝分潤）；用自己真金交易（vs prop firm 虛擬帳戶）。
- 通用硬條件：每階段 7% 回報（(transcript)「7%的回報之後,最少30天做到7%的回報。」91Hpt_LyJSE）＋「你唯一的條件就是,不可以虧超過10%」「它沒有限定每日虧程是多少」（虧程＝虧損）。
- 階梯（兩片平行）：入金 500 美金＋20 筆交易→5,000 跟單（總值階段）；孵化階段 1,000→10,000（10 倍，最多 2,000→20,000），分成 40%，最少 60 天；加速階段 25 倍（4,000→10 萬），91Hpt_LyJSE 講分成 50%、nzZ5oqmLjhM 講 H 分數要 70＋最少 50 筆；專業階段——91Hpt_LyJSE：「100萬美金的資金在跟你的單」分潤 80%；nzZ5oqmLjhM 更細：5,000→20 萬（分 60%）、1 萬→50 萬、2 萬→100 萬，分潤「最大到80%」。
- H 分數：「基本上就是要你的表現夠穩定,然後風險管控夠好」「你要打到90分其實真的不難的」（91Hpt_LyJSE）；分階段口徑：50 分開啟總值階段、60 分晉級孵化階段、70 分入加速階段（nzZ5oqmLjhM【推廣合作】）。
- 失敗處理：靜默階段——「它只是兩個星期不跟你的單」，兩次機會，「第三次」「你都需要從總值階段重新開始」；比考試爆掉重買便宜，係佢主張嘅風險優勢。
- 風格自由但拒暴力交易：「什麼樣的交易風格都可以」「你要用機器人交易,都沒有問題」，但「暴力交易,沒有一個交易機構,沒有一個券商是願意接受你的」（nzZ5oqmLjhM）。

**Step 7 — 帳戶增長藍圖與回報期望（講者藍圖非驗證統計）**

- 回報錨：月均 2%——「其實你可以做到24%的回報」一年，「就是一個月2%左右」，強調係平均唔係逐月（rE21_onS0uo）；「因為交易不是每個月都賺錢的啦」（mDpbsw81ftI）。
- 由開銷反推本金：每月開銷 5,000 美金÷2% → (transcript)「25萬美金的資金來做交易」（mDpbsw81ftI）；月出金 1 萬＋2% → 50 萬資金（rE21_onS0uo）。
- 【推廣合作】500→100 萬兩年藍圖：(transcript)「兩年的時間去做到100萬美金。」「兩年做到100萬是合理的,可以做到,也比較踏實,是可行的」（nzZ5oqmLjhM）——注意呢個係跟單資金規模非個人淨賺，且以逐級 7% 達標為前提，屬講者呈現嘅 aspirational roadmap，冇公開任何人行完全程嘅樣本。
- 心態配套：「我不要你一次大賺」「我只需要你穩定獲利」（91Hpt_LyJSE【推廣合作】）；「在AXE Select,暴賺是沒有用的」、要容錯率（nzZ5oqmLjhM【推廣合作】）；長期觀「給自己3到5年的時間吧,去穩定執行你的系統」（48pCaOfGGmA，無贊助口徑）。

**Step 8 — 通過／出金之後：戒飄與大資金態度**

- 反例（學員案例，講者轉述）：拎到 40 萬美金 funded 十天「成功出金了23000」後「他就變得飄了」「於是他的交易表現開始下滑」，連虧五個月先重建（mDpbsw81ftI）；另一學員 FTMO 40 萬＋六位數扶持後單筆拉高風險，一筆虧完帳戶爆（HeQiNekCZng）。心理重建機制 → `lun-trading-psychology`。
- 態度規則：「你要用那種操作大資金的態度去管理你的小資金的帳户」「你要把它當成是一個20萬美金的交易帳户來對待」；專注執行率而非收益率（48pCaOfGGmA）。
- 資金累積偏好（【推廣合作】語境）：「我不會太鼓勵你不斷的入金」，用利潤滾入解鎖下一階段，「你可以出境來享受一下生活,但是不要出太多」（91Hpt_LyJSE；出境＝出金）。
- 用自己資金時嘅停手線（「通常我會定給自己最多30%」虧損即出金停手 rE21_onS0uo）→ 規則本體歸 `lun-risk-management`，本 skill 只做銜接。

## Output（輸出）

本 skill 嘅輸出係**對話式分析指引**——唔生成檔案、唔代客報名、唔提供任何機構嘅現行條款。一份完整回覆應包含以下部分（每部分附 video id）：

1. **路線判斷**：用戶處於三步框架邊一步、數據門檻（50–100 筆）過咗未、應行考試定扶持計劃定雙軌。
2. **考試計劃**：目標→風險 %→可連虧次數→達標組合嘅倒推運算（照 xmHaONnNrCw 方法），連虧遞減同盈虧比門檻。
3. **規則陳述**：引用嘅每個計劃數字附出處＋as-stated 日期；Axi Select 數字必帶【推廣合作】標註；一律提醒以機構官方最新條款為準。
4. **回報期望**：月均 2% 錨＋開銷反推本金；增長藍圖標明**講者藍圖非驗證統計**。
5. **通過後守則**：戒飄反例、大資金態度、出金節奏。
6. **行動銜接**：考前數據 → `lun-backtesting-method`；通用風控 → `lun-risk-management`；考試系統規則 → `lun-price-action-toolkit`＋`lun-kill-zones-timing`；心態 → `lun-trading-psychology`。
