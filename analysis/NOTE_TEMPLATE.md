# Video Note 模板

> 每部影片一份 `analysis/video_notes/<video_id>.md`，依此結構撰寫。
> 沒有提到的欄位寫「未提及」，不要腦補。所有結論須可對應逐字稿內容。
> ASR 逐字稿可能有錯字（例如術語被誤認），引用原句時保留原文，可在括號附上推測的正確詞。

```markdown
# <影片標題>

- **Video ID**: <id>｜**日期**: <upload_date>｜**分群**: ict_core / price_action / method / risk_management / prop_firm / psychology_habits
- **一句話摘要**: <這部影片的核心主張>

## 術語定義（講者原話）
- <術語（英文 ICT 術語保留原文）> —「<逐字稿原句定義>」

## 策略規則（若為策略/教學影片）
- 適用市場與商品：外匯/黃金/指數/原油/其他；時段
- 時間框架：HTF 偏向用哪個框架、入場用哪個框架
- 進場邏輯：觸發條件、確認訊號、他當下看什麼（流動性/結構/PD Array/量）
- 出場邏輯：止損放哪裡及理由、止盈目標及理由、移動/分批方式
- 盈虧比與勝率：講者提及的數字

## 風控規則
- 每筆風險％、加減碼、資金/帳戶管理、prop firm 規則配合

## 心態原則／習慣
- <原則> —「<逐字稿原句>」

## 邏輯思維習性（原話佐證）
- <思維模式> —「<逐字稿原句>」

## 口頭禪/慣用語
- <高頻詞句>

## Skill-cluster tags
> 本片內容應歸入哪些候選 skill（可多個）：
> lun-ict-pd-arrays / lun-liquidity-analysis / lun-kill-zones-timing /
> lun-ote-entry-model / lun-price-action-toolkit / lun-risk-management /
> lun-prop-firm-playbook / lun-backtesting-method / lun-trading-psychology /
> （不合適則提議新 cluster 名）
- <tag>: <本片對該 skill 貢獻咗乜（一句）>
```
