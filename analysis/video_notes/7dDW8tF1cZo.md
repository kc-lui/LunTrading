# 《ICT交易完整系列#5》 完整的入場模型 ｜ ICT Entry Model

- **Video ID**: 7dDW8tF1cZo｜**日期**: 20250822｜**分群**: ict_core
- **一句話摘要**: 完整入場模型——趨勢跌到大時框流動性位（昨日/上週/上月/session 高低位）做假突破，等強動能結構破壞確認反轉，再等價格回調到 50% 以下便宜區嘅 FVG/Order Block 入場，止盈放對面大級別流動性位。

## 術語定義（講者原話）
- ICT 系統來源 —「他整理出來的這一套系統,其實就是很古老的價格行為。」「就是,倒是理論,威科夫理論來的。只是他從這邊學一點,那邊學一點,然後把它整理成他自己的故事。」（倒是理論＝道氏理論）
- Sell-Side Liquidity —「它跌到了一個支撐位置,或者是我們叫它為Sell-Side Liquidity。」
- 道氏趨勢規則 —「一個趨勢一直是下跌的。」「只要,價格不斷的跌破低位。」「然後,它的高位沒有被觸發到,價格永遠都是下跌趨勢。」
- 結構破壞 —「如果低位被突破了之後,這個低位被突破了,你就可以稱之為結構破壞。」（按上下文推測應為 高位被突破，下跌趨勢先至結束）
- 強動能條件 —「這個結構破壞呢,我們需要它是以強動能去做破壞的。」「如果它是低動能破壞的話,它其實價值沒有太大。」
- 便宜價格（PD Array 折扣區）—「那它便宜的價格在哪裡呢?」「就是50%以下,就是大約這邊以下。」

## 策略規則（若為策略/教學影片）
- 適用市場與商品：例子有外匯（價位 1.388）同黃金（「黃金好了。」）；時段以紐約時間三個 session —「它可以是亞洲盤的高地位。」「可以是倫敦盤的高地位。」「或者是紐約盤的高地位。」（高地位＝高低位）
- 時間框架：例子用 5 分鐘圖（「價格呢,在5分鐘的圖表」）、3 分鐘（「我可以去3分鐘的實況去看。」，實況＝時框）；關鍵位一定要大級別 —「它一定要是大石框的高地位。」「不可以是,喔!是一根K線,這個4小時K線的高地位。」（大石框＝大時框）
- 進場邏輯：①價格掃到大級別流動性位（昨日/上週/上月/session 高低位）做假突破；②強動能結構破壞確認反轉；③唔追價 —「我們不需要追漲殺跌。」；④等回調入 50% 以下便宜區 —「你要做多?你要在哪裡做?就是在FEG做。」（FEG＝FVG）「碰到了再做。或者是你要提前掛單也可以。」；已被碰過嘅 FVG 冇價值 —「這個FEG被碰到過了。」「對我來說沒有什麼價值了。」
- 出場邏輯：止損 —「止损點可以離開FEG,離開你的order block都可以。」「或者是直接離開整個U轉的地位都沒有問題。」，距離例子「就是我會離開5個點離開這個order block。」「OK,大約10個點左右。」；止盈 —「我們可以直接放到下一個BuySight Liquidity,下一個主力位置。」（BuySight＝Buy Side；主力＝阻力），例如喺昨日低位入就「那我就放昨日的高位作為止盈點。」
- 盈虧比與勝率：例子「這邊就有1比8的盈潰比。」（盈潰比＝盈虧比）、「剛剛好1比2.4的盈虧比。」、「1.7的盈潰比還不錯吧。」；勝率無具體數字，只講「它雖然盈虧比很大,勝率其實也還不錯。」

## 風控規則
- 每筆風險％、加減碼、資金管理：未提及；只提及止損離開結構 5–10 點嘅安全距離（「安全一點。」）

## 心態原則／習慣
- 接受個別虧損 —「那在這邊做空的話就虧掉了。」「但是也無所謂了。」「我們去找下一個交易機會就好了。」
- 要有基本偏向 —「但是呢,也不一定每一次其實都會碰到。」「所以你對價格的基本偏向還是要有的。」
- 長期執行一套系統 —「一套系統一套規則。」「不斷地每一天日復一日地去執行下去的話。」「你就會開始看到你的資金越變越多。」

## 邏輯思維習性（原話佐證）
- 先驗證來源再用系統：對「ICT 這一個人不是騙子嗎?」嘅質疑，佢答「你的顧慮是應該的。」，承認「確實發現 ICT 這一個人的交易」唔得，但系統本身有效 —「基本上,這個系統是沒有問題的,而且蠻厲害的。」
- 用散戶行為推演：先講早入場做多嘅人點被「全部被止损打掉了。」，再講追空嘅人點被夾，從而解釋自己點解等確認先入場
- 條件價值分層：破壞要強動能先有價值、流動性位要大級別先有價值 —「但是如果它是高石框,比如說亞洲盤,倫敦盤,紐約盤。」「或者是昨日上週,上個月的高地位,都很有價值。」
- 工具化圖表準備：入場前先設置指標 —「Hilo Yesterday, Last Week, and Last Month的這個工具。」「還有ICT Killzone and Pivot的工具。」，用顏色分昨日/上週/上月高低位做到「一目了然」
