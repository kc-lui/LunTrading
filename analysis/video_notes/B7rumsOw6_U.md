# 日內交易如何突破盲點 ｜ 不用去猜

- **Video ID**: B7rumsOw6_U｜**日期**: 20260528｜**分群**: price_action
- **一句話摘要**: 用日線判斷偏向、4小時/1小時趨勢驗證、5分鐘入場嘅多時框分析（配 EMA50、MACD、樞軸線）突破單一時框嘅盲點，跳過低質量機會，拉高盈虧比。

## 術語定義（講者原話）
- 偏向（HTF bias） —「在日線圖我們主要是判斷偏向。找到方向。我們的交易方向要做多?要做空?還是沒有方向?我們不要做」
- 趨勢驗證 —「所以4小時跟1小時主要做的是什麼?趨勢驗證。」「驗證跟日線圖偏向一樣的趨勢」
- 動能釋放的位置 —「我們可以判斷動能釋放的位置。就是我們要判斷價格要從哪裡?去到哪裡?」
- 背離（MACD divergence） —「背離就是第一次碰到這個低位的時候。它的動能非常的強。那第二次碰到類似一樣的低位的時候。你看它動能變得非常弱。所以這也是一個反轉的訊號」
- 盲點 —「這個就是所謂的盲點。就是4小時告訴你趨勢還是向上的」；喺 5 分鐘層面：「這個就是所謂的盲點」＋「就看不到這個order block擋在我們前面」（單一時框睇唔到其他時框嘅障礙）
- 5分鐘時框角色 —「5分鐘來判斷入場還有指引」「5分鐘是進階版的入場」
- 輸走線（推測：樞軸線 Pivot，P/R1/R2/R3） —「P就是入場」「從一個輸走線去到下一個,你的勝率是比較高」

## 策略規則（若為策略/教學影片）
- 適用市場與商品：未提及（全程用回測圖示範，冇講明商品；時段未提及）
- 時間框架：日線圖判斷偏向＋動能釋放位置；4小時＋1小時做趨勢驗證（「如果我想要做多,那我需要4小時跟1小時都是做多的趨勢」）；5分鐘做入場（「用5分鐘去做入場的話呢,我們的止损可以非常的窄」）
- 圖表設置：日線／4小時加 EMA50（「其實EMA50來做日內交易是最適合不過的」「200就太長了。100也是太長了。21又太短」）；1小時加 MACD（「MACD的好處就是我可以判斷動能」，MACD 用原廠設定）；5分鐘放樞軸線 P/R1-R3；另用支撐阻力轉換、趨勢線、K線反轉形態、order block
- 進場邏輯：三時框方向一致後先搵入場 —「要嘛我用破壞策略入場。要嘛我用OTE模型入場。要嘛我用做多的圖形交易入場」；要等 K 線收盤確認（「我不會當場去找做空。我至少要等這一根K線收盤先。有了熊市洞能我才去找做空」，洞能＝動能）；MACD 要擴張／背離配合；order block 擋路就跳過；order block 觸碰太多次就無視（「當它觸碰太多次,它已經失去價值了之後,通常我就可以無視它了」）；亦提到有人用 FVG 位（「有些人會說FVG的位置對吧?」）
- 出場邏輯：止損—「直順不用太遠」（直順＝止損），放喺 order block 之外（「那止筍或許我會放大一些」「我會離開這個order block」，止筍＝止損）；止盈—「直銀呢,到下一個結構就好」（直銀＝止盈），或以樞軸線 R1/R2/R3 做指引；管理—到位「我們就一定要鎖住利潤」「你要鎖住一個R也可以」，破位後「那我們就要積極地鎖得更高一些」，可以「你可以5分鐘EMA50後面做管理」做追蹤；隔夜可用評價保護（推測：平價保護／保本）掛住；接近目標時「通常我會主動」「手動出場」
- 盈虧比與勝率：單一時框做 1比3 同 1比5 回報一樣（「我回顧了我一整年的數據,我發現單一時框分析,我做1比3的盈虧比」「跟我做1比5的盈虧比,其實得到的最後的回報是完全一樣的」）；多時框目標 1比5、1比7、1比10；回測示範入面做出 1比2（管理後變 1比6）、1比4.3，錯過一單 1比9；追 R3 勝率最低（「你可以直接選擇拉非常高的盈益比直接去到R3。但是你的勝率就會比較低」「所以這邊有取捨」）；回測結果「我們只虧一比」

## 心態原則／習慣
- 冇符合條件就跳過，唔勉強 —「那既然我看不到我要的方向。那我可能可以選擇跳過」「等了幾天沒有交易,那就跳過、跳過、跳過」
- 條件唔齊全就等 —「但是MACD卻沒有背離」「動能卻很爛」「我們就繼續等待」
- 唔因單一訊號衝動入場 —「我不會因為一根釘形出來」「我就直接去做空了」（意指唔會咁做）
- 回測心態要同實倉一致 —「但是如果你可以把回撤的心態跟你真實表現一致性的話」「你一定得到一樣的成果」（回撤＝回測）；亦坦白「回撤的表現是比較容易的」「你的表現可能會差一點」

## 邏輯思維習性（原話佐證）
- 多時框一致性先行動 —「因為趨勢沒有一致性」「日線圖我知道我要做多」「四小時我知道好可以做多了」「但是一小時不可以」「所以我連五分鐘都不用去看」
- 先判斷值唔值得，唔值得連驗證都跳過 —「但是值得去做嗎?我覺得不太值得。那如果我覺得不值得的話。我連去試驗證這些我都不要做」
- 順序思考：偏向 → 動能 → 入場（「因為趨勢還沒有得到驗證」「我們不用去看動能」）
- 用簡單工具突破盲點 —「加一個MACD進來看一下動能」「加一個輸走線進來幫我們判斷我們的指引放哪裡」
- 事後檢視策略價值 —「你看到我們跳掉了很多比交易機會」而剩低賺嘅「盈益比都非常的高」
