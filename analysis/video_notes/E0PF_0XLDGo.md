# 《ICT交易完整系列#3》Weekly Market Profile | 解鎖你穩賺的節奏 ｜

- **Video ID**: E0PF_0XLDGo｜**日期**: 20250613｜**分群**: ict_core
- **一句話摘要**: 聰明錢以「時間邏輯」安排一週節奏——Weekly Profile 三種形態（經典擴張、週中反轉、橫盤震盪），先等高低位被流動性掃描再入場，「沒有掃描,沒有交易」。

## 術語定義（講者原話）
- Weekly Profile —「我們會專注在 Weekly Profile,就是週期的形態」
- 三種形態 —「第一個是經典的擴張形態。第二是週中反轉形態。而第三呢是紅盤震盪形態」（紅盤＝橫盤，ASR 誤認）
- 市場行為總邏輯 —「市場呢,要嘛就創造流動性,要嘛去尋找流動性,掃描流動性,或者是失衡了之後,要回到平衡點,找回平衡」
- SSL —「有一個是賣方的流動性。就是SSL。Sellside Liquidity」
- PD array（片中被 ASR 記成 PDI array）—「週一是動能累積,或者是價格會去往高時框的PDI array。就比較貴,或者是比較便宜的區域」

## 策略規則（若為策略/教學影片）
- 適用市場與商品：例子用 USD/JPY（USD Yen）日線；其他品種未特別限定；找不到節奏時「我們基本上就可以跳去找下一個交易品種」；時段未提及
- 時間框架：「基本上我們需要用比較大級別的實況,包括了日線圖,包括了1小時、4小時還是15分鐘,最低是15分鐘」；入場「我們可以用到一小時的入場就OK了」
- 進場邏輯：
  - 經典擴張：週一橫盤／動能累積，週二掃描週一高低位並「價格會創該週最高點,或者是最低點」，週二至週四流動性釋放，週五回調找平衡點；掃描＋反轉後入場，保守做法 —「如果你要保守一點的話,你就會等打破了高位在入場也是OK的」
  - 週中反轉：週一二無動能橫盤，「它到了星期三才少掉了週一的低位的話,那價格會在星期三之後,才反轉」（少掉＝掃掉，ASR 誤認），週三至週五釋放
  - 橫盤震盪：「週一,週二,週三,是橫盤的。但是,週四呢,少掉了週一,週二的高地位啦」之後才釋放；此形態較少見，且「如果你看到週一,週二,週三,都在橫盤的話」就不做
  - 不交易條件：「沒有掃描,沒有交易」；連續動能釋放無掃描都不做；用此方法「你週一呢,是不用交易的」（週一要交易須用 Daily Bias 等其他方法）
- 出場邏輯：到高時框 PD array 就出場，不戀棧 —「高實況的PD Array就好出場」「所以,到了下一個PD array,其實你就可以出場了」；不必持到週四週五 —「不一定要持常持到週四,週五不需要的」；止損例子放在上方 order block 區域 —「指引點就在剛剛提到的上面的那個訂單塊區域就OK了」（指引點推測: 止損點）
- 盈虧比與勝率：例子提及「這樣子就輕鬆做到了1比2的隱窺比」「你少少都有1比3的隱窺比」「這一筆有1.5的隱窺比」「那這一波,少少的1比10的隱窺比了」（隱窺比＝盈虧比，ASR 誤認）；勝率未提及

## 心態原則／習慣
- 貪心是虧錢主因 —「虧錢都是因為太貪心了。所以,你越想要持越久,你很快就失敗了」
- 錯過交易就放下 —「所以錯過了沒關係,我們去找下一個交易機會」
- 大量練習訓練盤感 —「你現在要做的就是去練習,不斷的練習,不斷的去找例子」「訓練了你的眼睛之後,你就會慢慢的開始掌握市場」

## 邏輯思維習性（原話佐證）
- 市場運作有時間邏輯，方向對仍會輸在節奏 —「很多教育員都沒有搞懂市場的運作是有時間邏輯的」（教育員＝交易員，ASR 誤認）
- 以流動性掃描作為一切入場的前提條件（先掃後做）—「我們要等結構被掃掉了之後,一個高位還是低位被掃掉之後,我們才可以入場」
- 釋放太快代表籌碼消耗、反向亦快 —「這邊釋放的速度有點太快,所以很容易籌碼消耗完,接下去下跌的速度也會很快」
- 用 PD array 貴/便宜（Premium/Discount）框架定目標 —「回到去了1小時的比較貴的價格。是比較貴的PD array。就是一個Premium的位置」
