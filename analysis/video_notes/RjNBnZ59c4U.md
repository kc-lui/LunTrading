# 判斷每日偏向的招式 ｜完整版教學

- **Video ID**: RjNBnZ59c4U｜**日期**: 20250702｜**分群**: ict_core
- **一句話摘要**: Daily Bias 係穩定獲利嘅核心——用高時框嘅高低位＋流動性掃描定偏向，再落低時框搵結構破壞，喺 FVG／Order Block 入場；偏向錯而入場條件未滿足時唔會虧。

## 術語定義（講者原話）
- Daily Bias（日內偏向）— 判斷「今天的偏向是什麼?你要做多?還是你要做空?還是你什麼都不要做?」嘅步驟；「对我来说Daily Bias比Market Profile更重要」
- 流動性原理 —「所以价格一定会从高扭动性的地方前往低扭动性的地方」（扭動性＝流動性）
- Daily Bias 流程總結 —「只是Daily Bias比较注重是高地位」「然后流动性扫描」「然后再去低死矿找结构破坏」「然后再做FEG那边入场」（高地位＝高低位；低死矿＝低時框；FEG＝FVG）
- Session 指標 —「它叫做session」，用嚟判斷亞洲盤／倫敦盤／紐約盤嘅高低位

## 策略規則（若為策略/教學影片）
- 適用市場與商品：例子用比特幣（日線＋4小時／1小時）；亦提及虛擬貨幣 7 天交易所以 Daily Bias 比 Market Profile 更適用；session 例子覆蓋亞洲盤／倫敦盤／紐約盤高低位
- 時間框架：高時框日線／4小時／1小時定偏向；低時框 15分鐘或 5分鐘搵入場；「低过5分钟我个人非常不认同」「其实低过15分钟我都觉得有点难做了」
- 進場邏輯：等高低位出現流動性掃描 → 落低時框等結構破壞 → 喺該段較便宜位置嘅 FVG 或 Order Block 掛單入場；偏向可以隨新嘅流動性掃描反轉 —「如果有流动性扫描的话那我的偏向会重做多变成做空就这么简单」
- 出場邏輯：止損稍微離開入場區域；止盈拉去下一個流動性／未被掃嘅高低位；日線圖出現新流動性掃描就考慮出場；用平價保護 —「你做一个评价保护」；沿途「你要锁定一部分的利润」；接近目標時手動離場 —「其实跌到这一边80%之后我会手动出场了」；ICT 原版做法唔同 —「那在ICT的讲法呢应该是当天进当天出啊」
- 盈虧比與勝率：例子做出「一比四十五的盈亏比」（自己都話「这个有点夸张」、要持倉四十幾日）；另一例「然后就1比3.8我们来看一下」；勝率具體數字未提及，只話隨性做「其实胜率还很高一下」

## 風控規則
- 每筆風險％：只提及舉例「你一巴仙的风险」對應 45 倍盈虧比等於賺五十巴仙；其餘資金管理、加減碼、prop firm 規則未提及
- 平價保護、鎖定部分利潤（見出場邏輯）

## 心態原則／習慣
- 偏向判斷係核心能力 —「很准的话那你要盈利其实比较容易的」；偏向錯嘅話「你都会慢慢的亏钱」
- 錯過交易唔追 —「那错过了没关系我们只需要等等它要么回来要么找下一个交易机会就好了」
- 大量復盤先實戰 —「你就一定要去做复盘」「做10单做100单复盘了之后」「你才去用比较小之星去实战测试」（小之星：推測為小資金／小注）

## 邏輯思維習性（原話佐證）
- 睇重偏向錯但唔入場就唔虧嘅不對稱性 —「但是如果你的偏向错了」「入场条件没有满足的话」「你不会亏」
- 帶入個人觀點、唔盲從 ICT —「因為有些地方我確實不是很認同他說的」
- 執行力導向：Asian 高低位雜音多、「波动率会比较高」，「如果执行不来的话」就用 4小時／1小時
