## 術語定義（講者原話）
- Trendline Breakout —「第一個策略叫Trendline Breakout,也就是趨勢線的破壞」；畫法：「我們需要把最少兩個影線結合起來」（底部影線連成趨勢線）
- Trend Line Pullback（第三次觸碰）—「我們只交易第三個位置,第三個rejection point」；理由：「因為我發現第三個位置,如果它並沒有直接破壞的話,通常它都會順著趨勢走」
- 頭肩形（Head and Shoulders）—「一個左肩,然後一個頭,一個右肩」；頸線判定：「所有的頸線破壞,對我來說是從左肩開始」
- Flag Pattern —「flag pattern」「就是骑行」（「骑行」應為「旗形」）；強動能後的短窄橫盤，「它适合用在任何一种直框」（「直框」應為「時框」），高時框更有效
- 等邊三角形 —「所以我们叫做等边三角形」「Symmetrical Triangle」，兩邊趨勢線慢慢收斂
- Triangle Top —（價格多次嘗試突破主力區域失敗、但低位越墊越高的形態）「这个时候」「就是我所谓的一个」「Triangle Top」，等破位交易
- 假突破 —（價格突破主力區域後）「但是很快速的直接回撤」，回到破壞前的位置即確認假突破
- Triple Test —（趨勢線被測試三次都打不破）「到了第三个触碰的位置」「有rejections的话」「我会直接交易」
- Divergence —「我们会用RSI」，設定：「我会把我的OVERSOT放在80」「然后OVERSOT放在20」「而不是70 30」（「OVERSOT」應為 Overbought/Oversold）
- London Breakout —（倫敦開市到閉市區間出現結構破壞就跟著方向走）理由：「因为伦敦开市之后」「所有的Transaction是最高的」
- Pin Bar 多時框策略 —「我都会用日线图」「或者是四小时图」「我要找的是PIN吧」（「PIN吧」應為 Pin Bar），再落到交易時框找破位
- Hit and Run（虛擬貨幣）—「所以hit and run」；原理：動能釋放太強時「筹码消耗的力度也非常的快」，反方向結構一破就跟著做，「其实还蛮适合用在虚拟货币的」

## 策略規則（若為策略/教學影片）
- 適用市場與商品：整體不限市場；London Breakout 指明「我只会用在这种GBPUSD」「或者是EURUSD」；hit and run 指明虛擬貨幣；例子提及 S&P500（一分鐘旗形）、黃金
- 時間框架：多數策略不限時框；「trend line pullback,用在高時框其實還蠻強的,用在低時框也可以」；旗形高時框更有效；London Breakout「通常我会用在一个小时的时框」；Pin Bar 策略用日線圖/四小時找 Pin Bar，再去一小時/15分鐘找結構破壞
- 進場邏輯：統一流程是先讀整體故事再進場 —「就是你了解整体故事了之后」「你再找到你的偏向」「你才来找你的策略」「你才来找你的入场位置在哪里」。每個形態都有兩種進場選擇：直接破位交易，或「破位回调之后再做交易」（講者現時個人偏向後者，但「有20%的机会价格是不做任何回调」直接走掉）。假突破可加 Fibonacci 佐證：「这个时候你打开皮波那级的话」「这个刚刚好是618」（「皮波那级」應為斐波那契）
- 出場邏輯：止損離開影線/K線/整個結構，頭肩形要「所以你要給你的單子多一點呼吸空間」；止盈常放在趨勢線形成的起點；旗形用第一波動能長度複製投影定止盈；橫盤環境（等邊三角形）「我反而会保守一对二」「一对三我就要出场了」；趨勢線破壞也可作出場訊號（提早出場）
- 盈虧比與勝率：普遍目標一對二至一對四；Triple Test「我甚至拿过一对二十的盈亏比」「单单这个Triple Test」；London Breakout 五天示範「只有一单只亏了」；破位回調交易止損較好、勝率較好但可能錯過機會，破位直接交易止損較大但不錯過機會

## 心態原則／習慣
- 學原理不背步驟 —「如果你要學會一套策略的話,你一定要學會該策略的原理以及背後的故事,而不是去記每一個步驟」
- 新手一個一個學 —「先一个一个来」「破坏交易先」，把一個策略執行力搞好再學下一個
- 連虧就停 —「只是如果我亏掉」「连亏两单的话」「我就不会再找同样的交易机会了」
- 沒有最好只有最適合 —「并没有一个更好的交易系统」「而是哪一个更适合你」；找到後「这个时候你需要去做测试」「你需要一个一个去测试」
- 時框跟生活配合 — 朝九晚五又累的話「你用长时况的方式去做交易」（「时况」應為時框）；有精神就「那我会更鼓励你去做短线交易」「那一天重复一次就够了」

## 邏輯思維習性（原話佐證）
- 圖表敘事思維：每個策略先問「整體的故事告訴我們什麼」—「跟着整体的故事去操作」，反例是「他们呢」「都会看到什么就交易什么」「根本不在乎整体的形态是怎样」
- 層次化決策：故事 → 偏向 → 策略 → 入場 → 止損止盈 → 管理，一步一步來（「更加的层次一步一步来」）
- 動能/籌碼推理：用動能強弱與籌碼消耗解釋形態 —「当趋势太强的时候」「筹码消耗的力度也非常的快」；低位越墊越高＝做多籌碼進場
- 接受不完美與取捨：「所以呢,你不能夠每一筆交易都抓得很精準」；破位 vs 破位回調各有取捨，「你可不可以接受」
- 同一位置多策略互相印證：同一張圖可同時用假突破、頸線破壞、趨勢線、旗形（「其实你就有好几个交易策略可以用」）
