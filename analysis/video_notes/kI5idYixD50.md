# 交易佈局 ｜ 抓準入場時機的關鍵 ｜

- **Video ID**: kI5idYixD50｜**日期**: 20250925｜**分群**: price_action
- **一句話摘要**: 教一整個星期嘅佈局三招——週日用 Forex Factory 篩出紅色數據嘅日期時間 → 數據公布後等高時框 PD array 出現流動性掃描（獵殺／假突破）→ 結構轉換後用入場模型（FVG／Order Block）入場，穩定食 1比2 至 1比4。

## 術語定義（講者原話）
- 流動性掃描 —「流動性掃描少的就是高時框的PD array」（少的：推測為「掃的」）；例子「就比如說是上週的高位低位啊,或者是昨天的高位低位,這些都OK的」
- 紅色數據（Forex Factory）—「紅色的數據呢,是最有價值的波動力是最大的」；「灰色是Holiday,就是銀行假期」；「黃色跟橙色影響力都不大」
- 獵殺 —（推測為 止損獵殺／stop hunt）即假突破形態：「價格出現了假突破。」「就是我們所謂的直勝獵殺」（直勝：推測為「止損」）
- 佈局嘅好處 —「有了絕對的清晰度呢,你做交易就不會慌了」；「好的布局入場時機會抓得很準」

## 策略規則（若為策略/教學影片）
- 適用市場與商品：外匯（例：AUD、紐西蘭相關品種）、原油（ASR 作「Proof Oil」，推測為 Crude Oil）、黃金（非農例子）、納斯達克100；時段跟紅色數據公布時間走，唔限固定 session
- 時間框架：HTF PD array 睇 4小時／1小時／15分鐘／5分鐘（「這個order block就是我們高時空的pd rate」；高時空＝高時框、pd rate＝PD array）；入場形態喺 1分鐘／3分鐘／5分鐘搵
- 進場邏輯：
  - 第一招：週日開 Forex Factory，用漏斗篩選「只打勾紅色跟灰色的數據罷了」；「我們只需要知道數據公布的時間還有日期就夠。數據的結果不重要。」唔猜方向；邊隻貨幣有紅色數據就「專注在跟澳幣有關的交易品種」（以 AUD 為例，因該貨幣品種動能最強）
  - 明確否定跨式掛雙向單：呢招佢用過，「它長期下來是不會幫你賺到錢的」，因為「很多時候兩單都會被觸發到,然後兩單都會虧」
  - 第二招：「第二招就是等待獵殺」—「等待那些品種在數據公布之後出現流動性掃描」，掃嘅係高時框 PD array（上週／昨日高低位、4H/1H 嘅 order block、失敗嘅 FVG 等；ASR 將 FVG 寫作 FEG／FBG／IFBG）
  - 第三招：「入場模型呢,跟ICT第五集分享的是一樣的」；「一定要等待數據公布之後」而且要同數據有關嘅品種先至最有效；流程＝假突破後「我們等待結構轉換了之後」（打破高位／結構破壞）再喺 FVG 或 order block 入場，「碰到了之後直接進」或掛單進
  - 無獵殺嘅情況（黃金非農例）：動能太強直接衝，order block 被強力破壞後「其實大家都可以考慮在這個order block做多啦」
  - 第一次激進入場失敗後可以入第二次，但「入场点我都会比较保守」「我都会等一个结构破坏啊还是什么在进」（簡體為 ASR 原文）
- 出場邏輯：止損拉開放喺獵殺低位／高位之外（原文碎片：止顺点拉开、指令点一样在上面；推測＝止損點、止盈點）；止盈唔好貪 —「大数据带来的动能很快就会被消耗完了」「很多时候消耗完了之后价格会很快的回到原本开始的地方」，所以「不要持太久」「千万不要贪心」；可以用高時框 PD array 做目標（例子做到 1比7：「这是1比7的incred比罗」，incred比＝推測 盈虧比）
- 盈虧比與勝率：單筆「可能抓1比2,還是1比3,其實都OK的」；「如果可以稳定的做到1比3 1比4的话 那你其实也可以得到一个更稳定的收入了」；警告「不一定有数据公布你就硬硬要做到1比10 1比20的盈亏比」；保守二次入場例子 1比4；勝率數字未提及

## 風控規則
- 單筆風險％：未提及
- 資金規模思維：真正重要嘅唔只係盈虧比，「资金也非常重要」—「你可以开更大的仓位」，細盈虧比都可以有可觀收入；交易班重點係點樣攞到「7位数的资金」（資金扶持／prop firm 方向）

## 心態原則／習慣
- 破除數據恐懼 — 唔好因為「數據公布的波動很大很危險」就避開：「當你交易了幾年,你就會發現到很多大波動都是因為數據公布後才會開始有的」
- 事前準備代替臨場反應 — 週日就做好成週佈局，知道自己要睇邊啲品種、等咩形態
- 唔貪心、合理出場 —「可以出厂了合理的价格出厂 是OK的」（出厂＝出場）

## 邏輯思維習性（原話佐證）
- 只攞可預知嘅嘢（時間／日期），放棄不可預知嘅嘢（數據方向、結果）—「數據的結果不重要。我們不去看。」
- 用歷史對照驗證未知 — 唔清楚某數據（例 Main Refinancing Rate）影響力大唔大，就「再去Trading View對比數據公布的時候」睇過往波動先決定要唔要理
- 多時框對照確認 — 假突破要同高時框 PD array 對比：「當然你也可以去跟高時框的PD Array去做對比。看看是否真的有獵殺的情況出現。」
- 動能有壽命 — 數據動能會被消耗完，所以出場目標要配合動能週期，唔好無限延伸
- 失敗後降激進度 — 第一次激進入場失敗，第二次自動轉保守（等結構破壞先入）
