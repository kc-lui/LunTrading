# 價格行為 (Price Action Trading) 完整版教學

- **Video ID**: pK6S7CEqMAk｜**日期**: 20240618｜**分群**: price_action
- **一句話摘要**: 將價格行為拆成四個關鍵部分——高時框K線定偏向、圖形識別、低時框趨勢分析、再組合成三步驟（日線 bias → 4H/1H 圖形 → 15m/5m 趨勢入場）的完整交易系統。

## 術語定義（講者原話）
- K線構成 —「它是由四個部分構成,有開盤價、收盤價、最高價和最低價」
- 實體 —「實體就是開盤價以及收盤價之間的比較厚實的區域」
- 引線 —「引線就是從實體延伸出來的線條」
- 動能 —「當開盤架和收盤架的距離越遠的時候,動能就越強」（開盤架＝開盤價、收盤架＝收盤價，ASR 誤認）
- K線力度 —「那我通常會把蠟燭分成三份」（依收盤價落在整根K線的上/中/下三分之一判斷強弱）
- Pinball（推測: Pin Bar）—「Pinball就是實體短,但是影線長的形態」
- 吞噬形態 —「第二種形態是吞噬形態,也就是所謂的Engulfing」
- 晨星/夜星 —「成星就是Morning Star,夜星就是Evening Star。成星和夜星形態,都是動能轉換的形態」（成星＝晨星，ASR 誤認）
- 頭肩型 —「Head and Shoulders是所有圖形裡面最強的圖形。準確率非常的高。而且,它也是趨勢反轉的一種圖形」
- Channel —「Ascending或Descending Channel,就是動能耗盡的一種表現」
- Flag —「Flag呢,是動能累積的一種形態。它是趨勢繼續的一個休息站」
- 三角形態 —「它是破位回調交易的最佳形態。三角形態呢,也是動能累積的一種形態」
- Rectangle —「Rectangle是動能累積的一種形態」

## 策略規則（若為策略/教學影片）
- 適用市場與商品：外匯（例1未指明品種）、黃金（例2）、Bitcoin（例3）；講者稱「價格行為適合用在任何一個交易品種」。時段：未提及
- 時間框架：HTF 偏向用日線；圖形在 4小時或 1小時找；入場在 15分鐘或 5分鐘 —「第二步呢,我們要在4小時或者是1小時裡面,等待圖形出現」
- 進場邏輯：三步驟 —「我們要用日線圖,找到Support Resistance」加上K線形態定多空偏向；4H/1H 等圖形（以頭肩型為主）出現並突破；再到低時框看突破趨勢的力度決定回撤深度，用掛單（sell limit / pending order）在回撤位入場；強趨勢時用 Fibonacci —「你可以選擇在38.2這個區域做多」。形態要出現在關鍵位置 —「重要的不是形態,重要的是這個形態在哪裡出現」
- 出場邏輯：止損盡量離開入場區域 —「你的止损點就盡可能的離開這個區域」；強趨勢回撤入場時「你要知道你的止损點要盡可能的離開50%」；止盈回到日線圖的支撐/阻力 —「止盈點就跟回我們的daily」；獲利後可移動止損 —「我就可以考慮把我的Stop Loss Large Break Even」（推測: 拉去 Break Even）
- 盈虧比與勝率：例1「一對4.8 的盈虧比」（扣除前一單虧損後淨賺約3R）；例2 掛單計算為 1比2.4（未成交錯過）；例3 Bitcoin「所以一對七的盈益比」；勝率未提及

## 心態原則／習慣
- 耐心與執行力是系統成敗關鍵 —「只是你的耐心和你的執行力一定要穿好」（推測: 一定要train好/跟得上）
- 錯過交易不執著 —「那這一單就跑掉了,就miss掉了。無所謂」
- 用前先復盤驗證 —「去做一些復盤。看它到底適不適合你」

## 邏輯思維習性（原話佐證）
- 位置優先於形態 —「重要的不是形態,重要的是這個形態在哪裡出現」
- 向左找歷史關鍵區 —「如果你往左看,你就會發現到,這邊有一個之前的主力區域」
- 多時框互相對應 —「在低時框的Engulfing,在高時框你是可以看到Pinbar的」
- 追求絕對清晰 —「可以給到你絕對的清晰度,也就是我很注重的Absolute Clarity」
- 用時鐘方向量化趨勢強度、據此調整止損止盈 —「就是用時鐘法,來幫我們判斷趨勢的強度」；三點鐘橫盤時「這個時候,所有的交易策略,所有的K線圖,所有的圖形都會失效」
- 以回撤力度推斷入場深淺 —「如果這麼強的力度,你就要期待它不會回撤到太深」
