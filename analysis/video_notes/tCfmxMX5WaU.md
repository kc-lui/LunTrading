# 《ICT交易完整系列#1》PD Array 完整教學｜為什麼大戶都在這個位置進場？

- **Video ID**: tCfmxMX5WaU｜**日期**: 20250514｜**分群**: ict_core
- **一句話摘要**: ICT 本質就是價格行為；PD Array（Premium/Discount 50% 劃分）加上其組成元素（Order Block、Breaker Block、FVG 等）用嚟判斷邊度係合理交易區，並且一定要等結構轉換先入場。

## 術語定義（講者原話）
- ICT —「ICT的全名叫做Inner Circle Trader」，由「Michael Hardestand」（推測為 Michael Huddleston）創建；核心思想係「就是市場是由大型資金所啟動的７不是由散戶所啟動的」（「７」為 ASR 雜訊字元）
- PD Array —「PD array７就是價格輸送的整個結構」；P —「P其實就是高價區」「就是Premium Zone」；D —「就是Discounted Zone」「就是低價區」
- 50% 劃分 —「任何低過50%以下的」「都是比較便宜的價格」；50% 以上係比較貴嘅價格，搵做空機會
- Order Block（訂單塊，ASR 誤寫「訂單快」）—「就是大型機構出手的區域」；多頭訂單塊「就是動能上漲前的最後一根K線」，而且「它一定是完全吞噬的」
- 失衡 —「就是價格突然間往一個方向波動」
- Breaker Block（破壞塊）—「就是反向主導的訂單塊」，即係原本嘅訂單塊被突破後做反向操作
- FVG（ASR 常誤寫「FBG」）— 價格短時間移動太快，「所以它留下了一個缺口」，而且「它是由三根K線組成的」；ICT 認為「這個FBG是會被填補的」（FBG＝FVG）
- IFVG —「就是Inverse FBG」，「就是它破壞了FBG的區域」，被破壞後做反向操作
- 隱藏 FVG（implied FVG）— ICT 嘅畫法係「它把這個引線的50%給畫出來」，上下引線各取 50% 形成區域
- Balance Price Range（平衡價格區間）—「基本上就是兩個反向的FBG」重疊形成嘅區域
- 拒絕塊（ASR「拒絕快」）—「拒絕快其實就是長引線」；流動性掃描「就是創造一個更低的位置」然後強烈拒絕反轉
- 真空塊（ASR「真空快」）—「是價格跟價格之間的一個很明顯的缺口」（開盤跳空）
- 補償塊（ASR「補仓快」）—「補仓快就是趨勢延伸失敗」加結構轉換所形成嘅區域

## 策略規則（若為策略/教學影片）
- 適用市場與商品：例子用咗比特幣（15分鐘圖）同黃金（日線圖）；時段未提及
- 時間框架：大時框（日線／1小時）搵 FVG／Order Block，小時框搵交易機會；Order Block 要「我們同時也要去小時框確認」有失衡同結構轉換
- 進場邏輯：價格回撤到 PD Array 元素（OB／FVG／拒絕塊等）；只喺整個波段 50% 以下搵做多（50% 以上搵做空）；唔好一掂到就做 —「不要一碰到就做交易」，要等結構轉換／結構破壞，「確認動能跟我們要交易的方向是一致性的時候」先入場，「勝率會更高」
- 出場邏輯：止損放喺結構外／區域外（例子入面「這裡是止存點」（推測：止損點））；止盈去下一個訂單塊／流動性位置；有例子用平價保護 —「反正1比1我們就被評價保護打出場」（評價保護＝平價保護/保本）
- 盈虧比與勝率：例子提及「大概1比10左右」、「盈盔比少少都有一比五」（盈盔比＝盈虧比）、1比2、1比3；勝率具體數字未提及

## 心態原則／習慣
- 唔追價 —「我不會去追」，錯過就搵「下一個機會」
- 對自己嚴格執行 50% 規則 —「我希望可以在50%以下」去做多，「這個是我對自己很嚴格要求的一個部分」
- 學完要做功課：去圖表搵盡量多符合條件嘅例子，「鍛鍊自己的眼睛」

## 邏輯思維習性（原話佐證）
- ICT 同價格行為本質相同 —「其實對我來說７本質上是一樣的東西７它只是用不一樣的字眼７用不一樣的故事７去講述整個市場的運作」
- 追求簡單有邏輯 —「它越簡單�越能容易理解�越有邏輯性�越好」
- 用條件清單過濾入場 — PD Array「就是我們入場前需要的一個清單來幫我們判斷」
- 冇確認就唔做，寧願錯過 —「沒有結構轉換」「不要做」
