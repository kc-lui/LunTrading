- **一句話摘要**: 一次過講完整套聰明錢（Smart Money）框架——Order Flow、結構破壞/轉換、流動性、Order Block、FVG——再組合成三個以流動性掃描＋結構訊號＋回調到高價值區為核心、目標 1:3 盈虧比的交易策略。

## 術語定義（講者原話）

- Order Flow（牛市）—「結合起來,我們就有一個牛市的市場。英文叫做Bullish Order Flow。」（由「一頭比一頭高的高點。同時我們再搭配一頭比一頭高的低點。」組成）
- Order Flow（熊市）—「結合起來,這就是我們的Bullish Order Flow。也就是下跌的趨勢。」（ASR 誤認：下跌趨勢應為 Bearish Order Flow）
- 市場碎形 —「結構是稅行的」「英文叫做Market is fractal。就是我們在小周期看到的趨勢。」（「稅行」推測為 碎形）
- BOS（結構破壞）—「結構破壞,代表趨勢會延續。它是一個訊號,它正在告訴你,原本控盤的那一方還在控盤。」；有效突破的條件：「我們要是實體突破,就是整根K線,實體是收盤在突破的外面。」
- CHOCH（結構轉換）—「接下來我們要說的就是Change of Character,叫做結構轉換。簡稱為CHOCH。」「這也就是告訴我們市場,可能會出現一個反轉訊號。注意是可能。」「它只是告訴你,賣方第一次擁有主導權。」
- Premium / Discount —「在這個低賣的位置,英文叫做Discounted Price,就是折扣價。在這個高賣的位置,英文叫做Premium Price,也就是抑價。」（「低賣」推測為 低買；「抑價」推測為 溢價）
- 流動性 —「流動性就是訂單。」「市場呢,永遠都是在找流動性。價格永遠會被吸引到,高流動性的地方。」
- Order Block —「英文叫做order block,它是啟動大行情的一根關鍵K線。」畫法：「就是牛4K線,或者是大動能釋放,往上推的話。那最後一根,熊4的K線呢?這一根,就是我們要的order block。」（牛4/熊4 推測為 牛市/熊市）
- Breaker Block（破壞塊）—「英文叫做breaker block」「這個失敗的order block,它就反轉了。」重疊時：「所以order block跟破壞塊重疊。這是一個非常高質量的交易區。」
- FVG —「但是第二根K線呢,是一根強動能的牛市K線。然後第一根K線跟第三根K線,都會有上下引線。然後這上下引線之間的區域呢,就是所謂的FEG,也就是比較公平的價格。」原理：「強動能釋放的時候,市場就失去了平衡。那市場是不喜歡失衡的狀態的。」（ASR 亦多次寫成 FEG/FBG）

## 策略規則（若為策略/教學影片）

- 適用市場與商品：不挑市場——「它是不挑市場的,你要用在米股,台股,外匯,期貨,指數,虛擬貨幣,港股,A股等等,都可以。」（「米股」推測為 美股）；示範用了黃金、特斯拉、蘋果、NVIDIA、納斯達克100、比特幣、外匯
- 時間框架：「我喜歡在大級別的時光,比如說日線圖還是四小時圖去判斷方向。一小時圖去看結構,去找區域。然後呢,5分鐘還是15分鐘去找入場。」（「時光」推測為「時框」）
- 進場邏輯——三個策略：
  - **策略一（ICT 動能 / OTE 型）**：「第一招是我們很久以前我在我的YouTube影片有分享過的,就跟ICI動能是一樣的。」（「ICI」推測為 ICT）「那就是我們有結構破壞,然後呢,動能釋放。」「價格回調到我們的Fibonacci,50到61.8,甚至更低些都OK。」條件：「不管是order block還是FVG,它需要跟其中一個Fibonacci的區間是有重疊。」入場確認 K 線：「我最喜歡的K線形態,就是吞噬形態。」
  - **策略二（最喜歡）**：「首先,我們需要流動性掃描。就是我們要看到價格有一個假突破。」之後「然後這個order block就反過來了。他本來是做多變成了一個失敗的order block。」完整條件重述：「我們會想要看到order flow是順著趨勢的。然後呢當價格回調的時候。我們要看到有流動性掃描。加上一個結構轉換。再回調到這個結構。然後我們就可以做多。」
  - **策略三**：「就是我們有一個order flow確定了之後。這邊沒有任何的流動性掃描的話。然後呢價格只是回調。然後上方卻出現了流動性掃描的話。這個時候我們可以標記我們的order block。」「等待結構破壞之後。價格再回來的時候。我們就可以做空。」入場可再降時框找流動性掃描提高盈虧比
- 他當下看什麼：流動性池位置——昨日/上週/上個月/去年高低位、亞洲盤/倫敦盤/紐約盤高低位、支撐阻力轉換；價格到流動性位置只做三件事：「第一,假突破。第二,暫時停留在流動性池。第三,直接突破流動性池。」最好時機：「最好的時機就是我們可以看到流動性掃描出現的時候。」
- Order Block 品質判斷：「一個高質量的order block,一個有價值的order block,你會看到價格是不會回調超過一半的。」「就是當它有強動能釋放之後,價格第一次回調到這個order block的時候,它的質量是最好的。」FVG 與 OB 同時存在時：「我發現到有FVG,有order block的話,我都會選擇order block。」
- 出場邏輯：止盈基本設定 1:3（可掛單湊足）；止損建議先放寬——「我會建議你們用寬一點的止损。來讓你的交易。會有更多的呼吸空間。不會這麼容易窒息。」；入場後出現反向流動性掃描必須保本——「你入場了,然後價格出現了流動性掃描,你一定要做評價保護。這是一個很重要的規則。」（「評價保護」推測為「平價保護」＝移到保本）；接近止盈未觸及會手動出場——「通常這種時候我會直接手動出場。就很靠近子孫的。我一定會手動出場。」（「子孫」推測為 止損/止盈 的 ASR 誤認，語境指止盈點）
- 盈虧比與勝率：「所以我最喜歡的盈虧比其實是1比3。」理由：「因為1比3盈虧比代表我其實每賺一次錢,我可以連虧三次。」策略疊加時勝率「已經差不多壓倒性。站在你這一邊了。」

## 心態原則／習慣

- 市場中性、不怪市場 —「就是市場,它是不針對任何一個人的。它對你是沒有任何惡意的。它也沒有在針對你。它只是一台會利用人性的機器。」「我們要做的是了解市場的機制。然後站在有動能的那一方。」
- 耐心是入場券 —「如果你連這一支幾個小時的影片都沒有耐心把它給看完的話,那你憑什麼讓市場覺得它應該要把錢交給你呢?」
- 接受錯過 —「因為你不可能每一個交易策略。每一個機會你都可以抓到。」
