# lun-multi-timeframe-analysis：多時框分析——三視角分工與大盈虧比工程（交易倫版）

> 本 skill 係交易倫 11-skill 體系嘅骨幹方法論——D1→4H/1H→5m/15m 嘅 top-down 分工流程出現喺 ≥12 份筆記（per profile §6.0 升格決定），並吸收兩個提議 cluster：動能回流系統（公開內容只係 MTF 骨架）同 A+ 交易篩選（第一條標準就係多時框同向）。所有規則同引文均出自佢 YouTube 影片嘅 ASR 逐字稿與筆記（引文照錄原文，含 ASR 誤字；正字對照見 `analysis/lun_trading_profile.md` §5）。唔好摻入 corpus 以外嘅通用 top-down 分析理論。完整原話證據全錄喺 [references/evidence.md](references/evidence.md)。佢嘅總定調：「當你用一個時框,你看一個時框來做交易的話,你只會看到浮出在海面上的那一角。」（GINdJCIIEvw，冰山理論）。

## When to Use（何時使用）

用呢個 skill 當你需要：

- 建立一次完整嘅 top-down 分析：日線/週線定偏向 → 4H/1H 驗證趨勢 → 低時框搵入場
- 解釋點解單一時框做大盈虧比「基本上就是靠猜」、多時框點消除盲點（冰山理論）
- 執行三時框同向一致性檢查，決定一筆機會做定跳過（一票否決規則）
- 用「大時框止盈＋小時框止損」工程出 1:5 以上嘅盈虧比結構
- 了解動能回流系統嘅公開骨架（同埋佢嘅知識邊界喺邊）
- 用 A+ 四大標準（多時框同向/第三浪/高盈虧比/催化劑）過濾垃圾交易
- 判斷唔同策略場景應該用邊套時框組合（主流程/精簡版/流動性掃描版）

**唔應該用嘅情況**：

- 單一時框內嘅 K 線/圖形/動能判讀（釘形、吞噬、頭肩、EMA50、MACD）→ 用 `lun-price-action-toolkit`（DRY：判讀材料由該 skill 持有）
- 具體回調入場觸發（結構破壞→回調 50–79%→OB/FVG 疊加）→ 用 `lun-ote-entry-model`
- OB/FVG/破壞塊等 PD Array 定義 → 用 `lun-ict-pd-arrays`；流動性池位置/掃描機制 → 用 `lun-liquidity-analysis`
- 時段/週節奏/數據日曆（幾時交易）→ 用 `lun-kill-zones-timing`；出場/移動止損/平價保護 → 用 `lun-exit-management`
- 交易頻率作為風控手段（月 3-5 筆嘅資金曲線論述）→ 主體歸 `lun-risk-management`（本 skill 只持有頻率觀嘅「篩選」面向）

## Workflow（分析流程）

做一次多時框分析時，按次序行以下步驟（次序本身係規則：「因為趨勢還沒有得到驗證」「我們不用去看動能」B7rumsOw6_U——上層未成立，下層唔使睇）：

**Step 1 — 揀時框組合（按策略場景，唔好混用）**

Corpus 內唔係一套固定組合，而係按場景嘅多個變體（照錄唔合併；contradiction map）：

| 場景 | 組合 | 出處 |
|---|---|---|
| 主流程（日內/動能） | 日線偏向 → 4H＋1H 驗證 → 5m 入場 | GINdJCIIEvw, B7rumsOw6_U |
| 三步驟圖形版 | 日線偏向 → 4H/1H 等圖形 → 15m/5m 入場 | pK6S7CEqMAk |
| 四層版 | 日線/4H 判斷方向 → 1H 睇結構、搵區域 → 5m/15m 入場 | xwsyfVf2l0k |
| 五時框版 | 週線＋日線偏向 → 4H＋1H 結構 → 5m 入場（「12345個實況」） | hmpAys3lJEo |
| 大盈虧比/長線 | 週線＋日線定偏向與止盈 → 4H/1H 確認 → 5m 或 1H 入場 | zgVlK7UBNTY, WmW5fQjK5Qg, xmHaONnNrCw |
| 流動性掃描版 | 中期圖/4H 判斷掃描 → 30m/15m 入場 | whJg0lgPbFo |
| 精簡版（單源） | 1H 結構偏向 → 5m 入場：「就這麼簡單」 | fLN20X1dP48 |

時框下限有矛盾口徑，照錄唔裁決（profile §7.3.5）：「低过5分钟我个人非常不认同」「其实低过15分钟我都觉得有点难做了」（RjNBnZ59c4U）vs 數據交易 1m/3m/5m（kI5idYixD50）、加倉系統 1 分鐘（PypFn7GaVfE）。回答時按用戶場景揀對應行，唔好宣稱有單一「正確」組合。

**Step 2 — 宏觀視角：定偏向＋動能釋放位置**

日線（或週線）層答三選一：「要做多?要做空?還是沒有方向?我們不要做」（B7rumsOw6_U）；同時「判斷價格要從哪裡?去到哪裡?」（動能釋放位置＝未來止盈參考）。判讀材料（釘形/吞噬/頭肩/EMA50/OB/支撐阻力）→ 轉介 `lun-price-action-toolkit`＋`lun-ict-pd-arrays`。高時框優勢：「低時框。大多數時間的趨勢都是非常的醜陋的。所以高時框反而會比較乾淨」（7yDxPi7Roh0）。冇方向或者唔值得：「那如果我覺得不值得的話。我連去試驗證這些我都不要做」（B7rumsOw6_U）——直接跳過，唔使落 Step 3。

**Step 3 — 趨勢驗證：一致性一票否決**

4H＋1H 要「驗證跟日線圖偏向一樣的趨勢」；「如果我想要做多,那我需要4小時跟1小時都是做多的趨勢」（B7rumsOw6_U）。驗證成立門檻係轉勢完成：「從做多趨勢轉換成做空趨勢了之後。我們的趨勢驗證才算成立。」（GINdJCIIEvw）。**一票否決示範**：「日線圖我知道我要做多」「四小時我知道好可以做多了」「但是一小時不可以」→「所以我連五分鐘都不用去看」(transcript, B7rumsOw6_U)。缺確認就等，唔好硬入：「我需要等多一根4小時的K線」（zgVlK7UBNTY）。三時框齊晒＝訊號升級：「當3個時光都指在同一個方向的時候呢,這個時候市場就在告訴你,大行星要來了」（k0ESC6XYz50）。

**Step 4 — 執行視角：低時框入場＋大盈虧比工程**

三時框同向後先落執行時框搵入場（具體觸發轉介 sibling：「要嘛我用破壞策略入場。要嘛我用OTE模型入場。要嘛我用做多的圖形交易入場」B7rumsOw6_U → `lun-price-action-toolkit`/`lun-ote-entry-model`）。本 skill 持有嘅係盈虧比結構原理：

- **止盈跟大時框**：「我的止盈點�是跟著日線圖或者是周期圖的」（xmHaONnNrCw）；「止盈點基本上就可以放很遠」——前提係「我們做的偏向是跟著宏觀視角一樣方向」（GINdJCIIEvw）
- **止損跟小時框**：「因為我們是在低時框入場嘛,所以我們子孫也其實會更窄」（GINdJCIIEvw；子孫＝止損）；「用5分鐘去做入場的話呢,我們的止损可以非常的窄」（B7rumsOw6_U）
- **一句總結**：(transcript)「很大的時光去找到我止盈位置。」「很小的時光入場。」「這就是我盈益比這麼高的秘密。」（MjPZizFnX-E）
- **單一時框上限**：「你可以做到1比2的盈亏比就已經很好了」（GINdJCIIEvw）；佢一年數據入面單一時框 1:3 同 1:5 「得到的最後的回報是完全一樣的」（B7rumsOw6_U，自述）
- **執行機制（單源）**：大時框搵到機會設警報器，響咗先「切換到5分鐘的時框�去找交易機會」（xmHaONnNrCw）；timing 兩難：「太早入場�很容易被掃掉�你太晚入場�你就錯過了」
- 止損寬窄表面矛盾（profile §7.3.8）：「止損唔好太窄」（hkCvRoLc3Nk 等）vs 低時框「非常的窄」——係同一體系兩層：入場時框**內**要留呼吸空間，靠**降時框**縮絕對距離；解釋時兩層都要講。

**Step 5 — 子節：動能回流系統（公開骨架）**

> **知識邊界（唔可以逾越）**：動能回流嘅**完整 1234 招清單係付費班內容，公開影片冇教**——「細節我就不多講了,有興趣可以直接進入交易輪交易班去學習」（WmW5fQjK5Qg）；「就是我們動能回流的1234招」僅點名未展開（xmHaONnNrCw）；MjPZizFnX-E 進場細節同樣未公開（per profile §7.1.1）。回答時必須聲明呢個邊界，**唔可以**用外部知識或推斷補完清單，**唔可以**將下面骨架包裝成完整系統。

公開 corpus 透露嘅骨架（＝MTF 流程嘅一個具名應用）：

1. **先找價格會去邊（止盈先行）**：「我們的第一步通常是要找價格可能會去到哪裡?」（zgVlK7UBNTY）——目標常設喺流動性重疊位（機制→`lun-liquidity-analysis`）
2. **多時框逐層確認**：WmW5fQjK5Qg 個案＝週線結構破壞＋釘形支撐 → 日線 OB 觸碰兩次＋EMA50 釘形 → 1 小時假突破後「回流到1小時的EMA50」兼支撐阻力轉換——「滿滿的共識」
3. **低時框精準入場**：5 分鐘（zgVlK7UBNTY「1比60...我們會用5分鐘的時光去入場的」）或 1 小時完成形態（WmW5fQjK5Qg）
4. 系統定位（自述）：「這個系統專門抓比較高的盈虧比,勝率也不低」（MjPZizFnX-E）；實例 Russell 2000 1:22.45（WmW5fQjK5Qg）、原油理論 1:60＋（zgVlK7UBNTY，錯過咗嘅機會）——全部未經獨立對帳。

**Step 6 — 子節：A+ 交易篩選四大標準〔單源低信心：k0ESC6XYz50 一片〕**

過濾層——決定「呢筆值唔值得做」：「多時光同向,我們只抓第三浪,我們要高的銀益比,然後最後我們要確認有稅劃劑,明顯的稅劃劑」（k0ESC6XYz50）：

| # | 標準 | 要點 |
|---|---|---|
| 1 | 多時框同向 | 即 Step 3 嘅輸出；「每一個時框的偏向都是一樣的」 |
| 2 | 只抓第三浪 | 「第3浪就是趨勢最強的一段」；等第一浪形成先抓，不摸頂摸底（浪型判讀→`lun-price-action-toolkit`） |
| 3 | 高盈虧比 | 即 Step 4 嘅輸出；「盈益比要大,這樣子我們做更少的交易」 |
| 4 | 催化劑/共時 | 大數據公布/關鍵位反轉/突破；「共時越多越好」（confluence 口徑→`lun-price-action-toolkit` 2–3 底線/3–5 理想） |

判定：(transcript)「基本上沒有催化劑的交易,都是垃圾交易。」四項唔齊「很有可能這筆交易機會是垃圾交易機會」。頻率觀：(transcript)「專注一個月做3-5筆高質量的交易,你會看到你的帳戶是飛著增長的。」（月 3-5 vs 早期週 3-5 屬口徑演化，以後期為主——profile §7.3.6；資金曲線論述歸 `lun-risk-management`）。挑剔精神多片旁證（GINdJCIIEvw「你要告訴市場,你想要看到什麼」；xmHaONnNrCw 1比3 門檻；MjPZizFnX-E「A加級別」），但**四大標準清單本身係單源**。

**Step 7 — 同 sibling 整合（本 skill＝路由層）**

本 skill 嘅輸出係一個「做/唔做＋每層用咩時框」嘅路由決定：偏向判讀材料→`lun-price-action-toolkit`；入場觸發→`lun-ote-entry-model`；時段配合（例：「因為是指數,所以我可能會等到倫敦盤開始了之後」GINdJCIIEvw）→`lun-kill-zones-timing`；止盈執行/移動止損→`lun-exit-management`；倉位→`lun-risk-management`。

## Output（輸出）

本 skill 嘅輸出係**對話式分析指引**——唔生成檔案，唔落單，只提供按交易倫口徑嘅多時框判斷。一份完整嘅 MTF 分析回覆應包含以下五部分，每部分引用對應規則（附 video id）：

1. **時框組合宣告**：按場景揀咗邊套組合（主流程/圖形版/長線版/掃描版/精簡版）同點解。
2. **逐層判定**：宏觀偏向（多/空/冇方向）→ 4H/1H 驗證成立與否 → 一致性檢查結果；任何一層 fail 就明確講「跳過」，唔好落到下層。
3. **盈虧比結構**：止盈參考（大時框邊個位）＋止損參考（小時框邊個位）＋粗略盈虧比；引用「大時框止盈小時框入場」原理。
4. **A+ 篩選核對**：四大標準逐項核對——並標明呢層係單源低信心。
5. **行動銜接**：講明下一步轉介邊個 sibling skill（判讀→price-action、入場→ote、時段→kill-zones、出場→exit），唔好即場代答超範圍問題；涉及動能回流時附知識邊界聲明。

## 實例（corpus 內示範）

### 例一：一票否決嘅完整回測示範（B7rumsOw6_U）

日線 EMA50＋動能定偏向 → 4H/1H 驗證 → 5m 入場嘅 bar-by-bar 回測：多次「跳過、跳過、跳過」，剩低嘅單「盈益比都非常的高」（做出 1:2 管理後變 1:6、1:4.3）。示範重點：MTF 嘅價值一半喺「唔做」——唔一致就連下層都唔睇。

### 例二：原油 1:60 解剖（zgVlK7UBNTY）

動能回流骨架完整走一次：週線定偏向＋止盈（左側「止盡裂殺」重疊位）→ 日線吞噬確認（質量自評「不算A加級別,因為影線比較長」）→ 4H 結構破位回調 OB（OTE 成立→`lun-ote-entry-model`）→ 5m 入場。「你要做到1比60多的盈虧比,不是在1小時入場的」。示範重點：同一偏向下，入場時框決定盈虧比量級；另注意呢筆係**錯過咗**嘅機會，數字係理論值。

### 例三：週線→日線→1H 逐層共識（WmW5fQjK5Qg）
