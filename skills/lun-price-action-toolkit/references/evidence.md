## 1. 動能兩階段框架（rdXofMdxNEQ 主教材）

- 「市場動能主要分成兩個階段。」「動能釋放,以及動能積累。」（rdXofMdxNEQ）
- 動能積累：「當市場上的籌碼都耗盡了,就會進入到一個橫盤的狀態。」「而這個階段的波動是相當不穩定的,是非常沒有規律的。」（rdXofMdxNEQ）
- 避開積累期：「聰明的你一定要知道,避開沒有動能的階段,或者是動能累積的階段。」（rdXofMdxNEQ）
- 動能確認嘅意義：「我們等待動能出現了再進場,是因為我們要肯定,這個時候到底是誰控制了市場。是買家還是賣家。」（rdXofMdxNEQ）；「這個時候我們根本不知道最後,多頭的動能更大,還是空頭的動能更大。」「所以你在這個時候進場的話,完全沒有優勢。」（rdXofMdxNEQ）
- 確認條件：「它一定要是強大的動能K線。」「它可以是一根或者是好幾根組合起來。」（rdXofMdxNEQ）
- 回調預警：「當你看到K線越變越短的時候。」「這個時候你就需要去注意。」「因為回調很有可能即將開始了。」（rdXofMdxNEQ）
- 籌碼消耗解讀：「當動能開始釋放之後。」「籌碼會漸漸地被消耗。」（rdXofMdxNEQ）；「当趋势太强的时候」「筹码消耗的力度也非常的快」（VjSB-VRyxWI，hit and run 原理）；「因為它加速下跌的時候代表籌碼加速消耗。」（JtPN1rBq5h0）
- 只做動能確定：「我們只能在動能釋放很確定的時候在入場」「我們的勝率會比較高」「而不是在動能很模糊的情況下入場」（OANImZtkkeM）
- 訓練法：「你現在需要做的就是練習。」「練習找出100個,」「確定了動能在入場的交易機會。」（rdXofMdxNEQ）

## 2. K 線基礎與力度三分法（pK6S7CEqMAk 主教材）

- K 線構成：「它是由四個部分構成,有開盤價、收盤價、最高價和最低價」；實體「就是開盤價以及收盤價之間的比較厚實的區域」；引線「就是從實體延伸出來的線條」（pK6S7CEqMAk）
- 動能定義：「當開盤架和收盤架的距離越遠的時候,動能就越強」（pK6S7CEqMAk；開盤架/收盤架＝開盤價/收盤價）
- 力度三分法：「那我通常會把蠟燭分成三份。在牛市K線的蠟燭裡,當收盤架是在三分之一的上方,那對我來說,這個就是力度很強的牛市K線。當收盤架在三分之一的中間區域的話,這個力度就還好,也就是比較neutral。當牛市的K線收盤架在三分之一的底部,這個就是一個非常弱的牛市K線。」(transcript, pK6S7CEqMAk)；後續：「在特定的條件裡,我甚至可以把它當成是一根熊市的」K線（transcript, pK6S7CEqMAk）
- Pin Bar：「Pinball就是實體短,但是影線長的形態」（pK6S7CEqMAk；Pinball/PIN吧＝Pin Bar）
- 吞噬：「第二種形態是吞噬形態,也就是所謂的Engulfing」（pK6S7CEqMAk）；入場確認 K 線偏好：「我最喜歡的K線形態,就是吞噬形態。」（xwsyfVf2l0k）
- 晨星夜星：「成星就是Morning Star,夜星就是Evening Star。成星和夜星形態,都是動能轉換的形態」（pK6S7CEqMAk；成星＝晨星）
- 多時框對應：「在低時框的Engulfing,在高時框你是可以看到Pinbar的」（pK6S7CEqMAk）
- K 線質量評級實例：「當然這一根吞噬K線的質量,我覺得不算A加級別,因為影線比較長」（zgVlK7UBNTY）

## 4. 趨勢、結構與時鐘法

- 上漲趨勢定義：「當一個趨勢是在上漲趨勢的時候,你就會看到價格不斷會創新高,Higher High」，同時創 Higher Low，「價格永遠不可以打掉Higher Low」；「打掉了最新的最靠近的Higher Low之後,上漲趨勢就結束了」「但是下跌趨勢反而還沒開始」（ofQ--jkHTm4）
- Order Flow（牛/熊）：「結合起來,我們就有一個牛市的市場。英文叫做Bullish Order Flow。」（xwsyfVf2l0k）
- 市場碎形：「結構是稅行的」「英文叫做Market is fractal。就是我們在小周期看到的趨勢。」（xwsyfVf2l0k；稅行＝碎形）
- BOS：「結構破壞,代表趨勢會延續。它是一個訊號,它正在告訴你,原本控盤的那一方還在控盤。」（xwsyfVf2l0k）；「這個突破前高位的這一個區域,就叫做 VOS,也就是我們俗稱的結構破壞」（ofQ--jkHTm4；VOS＝BOS）
- 有效突破＝實體收盤：「我們要是實體突破,就是整根K線,實體是收盤在突破的外面。」（xwsyfVf2l0k）
- CHoCH：「接下來我們要說的就是Change of Character,叫做結構轉換。簡稱為CHOCH。」「這也就是告訴我們市場,可能會出現一個反轉訊號。注意是可能。」「它只是告訴你,賣方第一次擁有主導權。」（xwsyfVf2l0k）
- 趨勢線畫法：「我們需要把最少兩個影線結合起來」（VjSB-VRyxWI）
- Trend Line Pullback（第三次觸碰）：「我們只交易第三個位置,第三個rejection point」；「因為我發現第三個位置,如果它並沒有直接破壞的話,通常它都會順著趨勢走」（VjSB-VRyxWI）
- Triple Test：（趨勢線被測試三次都打不破）「到了第三个触碰的位置」「有rejections的话」「我会直接交易」（VjSB-VRyxWI）；「單單這個Triple Test」「我甚至拿过一对二十的盈亏比」（VjSB-VRyxWI）
- 時鐘法（趨勢強度）：「趨勢解析呢,我會用最傳統的方法,就是用時鐘法,來幫我們判斷趨勢的強度。如果趨勢是在一點鐘方向」「所以,所有的破位交易都非常的賺錢。而且,你的止損點不需要太大。如果是兩點鐘的趨勢,市場還是往上走了。但是,回撤的力度會比較大。」「你的止損點要大一些。止盈點也不要太大。三點鐘的話,基本上我們可以暫時不交易。三點鐘的趨勢就是橫盤」「這個時候,所有的交易策略,所有的K線圖,所有的圖形都會失效。4點鐘呢,就是開始往下跌。但是,跌的力度沒那麼大。回撤的深度會比較深一些。」「你的止損點要稍微的保守一點。5點鐘的話,下跌的趨勢是相當的強的。所以,這個時候所有的交易機會,的止損點都不需要太大。」(transcript, pK6S7CEqMAk)
- 高時框較乾淨：「尤其是在低時框。大多數時間的趨勢都是非常的醜陋的。所以高時框反而會比較乾淨」（7yDxPi7Roh0）

## 5. 指標工具（EMA50／RSI／MACD／Pivot）

- EMA50（中長線口徑）：「因為在中長線來說的話,50天是非常有效率的,它是非常有效的一個轉折點。200天就太長,20天就太短,所以50天來判斷偏向剛剛好」（7yDxPi7Roh0）
- EMA50（日內口徑）：「其實EMA50來做日內交易是最適合不過的」「200就太長了。100也是太長了。21又太短」（B7rumsOw6_U）
- EMA50 過濾規則：「如果價格是在EMA上面的話,那整個趨勢會比較偏向上升」（YeGLUuh3eCg）；「這一邊我肯定不會進。因為價格在YM50下面」（7yDxPi7Roh0；YM50＝EMA50）；「我自然而然會等價格在EMA50上面之後,有破位之後,我才入場」（k0ESC6XYz50）
- 兩步法：「第一步就是你要判斷動能」→「我們去用EMA50來判斷我們的趨勢」；「最好做的是,就是強動能突破加上EMA都一致性的話,這個機會就很完美了」（YeGLUuh3eCg）
- 早期版本（2023）：100 日平均線——「條件是你需要動能線來突破100日平均線。」「或者是動能產生之後價格回調到100日平均線。」（rdXofMdxNEQ）
- 三線系統（2025）：5 分鐘 EMA 21/50/200——「真的21在上面,50在中間200在下面。這個時候就是多頭的趨勢了。」；觸發「價格呢,必須要有一個強動能的K線,推開50,推開21。」「推開了之後,這邊就是我們的入場位置了。就這麼簡單。」（fLN20X1dP48）
- RSI 用途：「RSI工具!其實就是!幫助我們!判斷動能!」「RSI14週!」（fTRv2HhTJUk；14週＝14週期）；「因為RSI是判斷動能」（fLN20X1dP48）
- RSI Divergence 設定：「我们会用RSI」「我会把我的OVERSOT放在80」「然后OVERSOT放在20」「而不是70 30」（VjSB-VRyxWI；OVERSOT＝Overbought/Oversold）
- RSI 破位過濾（做多）：回調動能唔可以強——RSI「是不可以跌超過50的」，超過就「這個回調的動能!太強了!我們不要!」；新突破要 RSI「很!靠近!70的!這個位置!」或超過 70；做空鏡像靠近 30（fTRv2HhTJUk）
- RSI 順勢過濾：做空時「這個時候也要低過50」（fLN20X1dP48）
- MACD：「MACD的好處就是我可以判斷動能」（原廠設定）；背離——「背離就是第一次碰到這個低位的時候。它的動能非常的強。那第二次碰到類似一樣的低位的時候。你看它動能變得非常弱。所以這也是一個反轉的訊號」（B7rumsOw6_U）
- 指標平衡區失效：「當市場在一個平衡的區域的時候,你任何技術指標,均線還是RSI這些都是完全沒有什麼意義的。」（xwsyfVf2l0k）
- 指標宜少：「用太多的工具」「或者是用太多的指标」「会让我们的交易表现很糟糕」「所以越简单越好」（s4on4yJCLII）
- Pivot Point：「一個叫做Pivot Point Standard,它就是輸走點。」「輸走點就是把最高價、最低價,還有收盤價結合起來,找到一個平均值。」（7j7_mhfda38；輸走點＝樞軸點）；設定「那我們需要用的輸走點的實況計算是用daily,就是日線圖來計算。那你可以選擇traditional就夠了。」「你可以把S4跟S5還有R4跟R5都點掉。」「交易到S3或者R3就足夠了。」（7j7_mhfda38）
- Pivot 紀律：「一定要在pivot的位置。」rejection 或假突破先入場；「當價格沒有在任何一個Pivot裡面的話,我們就不交易。」「你可以設置一個警報器在任何一個Pivot。有碰到了,你才看。沒有碰到的話就不理它。」（7j7_mhfda38）；「P就是入場」「從一個輸走線去到下一個,你的勝率是比較高」（B7rumsOw6_U）

## 6. 破位、假突破與判斷框架

- 破位嘅必然性：「有趨勢!就一定會有破位!」「價格不可能一直震盪下去的!動能累積到一個程度!破位就會發生!」（fTRv2HhTJUk）
- 第一原則：「第一次破位永遠不要直接判斷他是真實突破。」「所以我們不要成為流動性的犧牲品的話。我們就不要直接一破位就交易。很多時候破位我們都要保持懷疑的。」（JtPN1rBq5h0）
- 站得住：「它是否站得住?如果它站得住的話,你會發現到一定會有強動人把價格給壓下來。但是呢,它卻壓不了太多。」「當它壓不了太多的時候,這個時候我們等待一個新的動能來襲了之後,其實我們就可以判斷動能延續了。」（JtPN1rBq5h0；強動人＝強動能）
- 站唔住→反向：「它衝破了。那它站得住嗎?看到它站不住了之後。那我們可以做反向交易。或者是它站得住。那我們等待破壞。然後我們直接抓下一波動能。」（JtPN1rBq5h0）
- 兩個判別條件（流動性課版本）：「你就要知道它破壞的時候Ｖ它是否是搶動能K線破壞」「第二Ｖ它是否站得住」（yZoSW3DGRGI；搶動能＝強動能）
- 假突破定義：（價格突破主力區域後）「但是很快速的直接回撤」，回到破壞前的位置即確認（VjSB-VRyxWI）；「因為價格只是稍微一根K線就突破了」「我可以說這一塊是假突破」（ofQ--jkHTm4）
- 假突破成因（散戶視角版）：「因為在我們想要進場的那個位置!聰明錢啊!還是那些資金啊!還是機構等等!」「他們都想要在那邊止盈出場」「這其實就是市場的運作方式」（fTRv2HhTJUk；機制詳解歸 lun-liquidity-analysis）
- 追突破嘅代價：普通見突破就追「長期下你的勝率其實是很低的」（fTRv2HhTJUk）
- 破位交易三步清單（fTRv2HhTJUk）：「所以!我們的第一步是!確認!偏向!」（動能釋放定偏向、EMA50 輔助）→「我們需要它回調!一定要有回調!」（RSI 唔破 50、「他回調的時候!不要超過!EMA50!」）→ 回調後再突破先入場（RSI 靠近 70/30）；失敗後再入場：「答案!是!可以的!」只要第二次回調一樣冇碰 50，「可以!給它!多一個!機會!」
- 條件前置思維：「但其實在等待破位發生之前齁!我們就已經要確認好這個破位如果發生的時候它的勝率一定會很高!」（fTRv2HhTJUk）
- 倫敦破位判別條件（QZNzq-BunA4）：「傳統的倫敦破位只做破位。但是,如果你只做破位,你的勝率非常的低」；區間闊——「相差一段距離就代表亞洲盤其實有動能釋放。這種時候我們會等待倫敦假突破」；區間窄——「並沒有任何動能釋放。那這個時候我們專注的是倫敦破位交易法則」；「不一樣的條件。我們就要用不一樣的形態」；適用品種「我發現任何跟英鎊有關的品種,或者是歐元有關的品種都OK」（時段規則歸 lun-kill-zones-timing）
- 主觀成分：「所有的交易策略都有80%的規則」「20%你需要主觀判斷」（QZNzq-BunA4）
